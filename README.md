# F1 Team Profiles — Academic Exercise

**English / Español**

## English
A small collaborative web exercise presenting two Formula 1 team-driver profile cards. A button reveals predefined sample statistics for one profile.

**Concepts demonstrated:** semantic HTML sections, CSS Flexbox, responsive card layout, JavaScript DOM events, dynamic text updates, and separation of structure, styling and behavior.

**Technology:** HTML5, CSS3 and Vanilla JavaScript.

**Run:** Open index.html in a browser. No backend or external dependencies are required.

**Data note:** Statistics are illustrative sample values, not official Formula 1 records. The current page includes student names; anonymize third-party names before promoting it as a public portfolio artifact.

## Español
Ejercicio web académico y colaborativo que presenta dos tarjetas de perfiles de pilotos de equipos de Fórmula 1. Un botón revela estadísticas de ejemplo predefinidas para uno de los perfiles.

**Conceptos demostrados:** secciones HTML semánticas, Flexbox en CSS, tarjetas adaptables, eventos del DOM en JavaScript, actualización dinámica de texto y separación de estructura, estilos y comportamiento.

**Tecnologías:** HTML5, CSS3 y JavaScript puro.

**Ejecución:** Abre index.html en un navegador. No requiere backend ni dependencias externas.

**Nota sobre los datos:** Las estadísticas son valores ilustrativos, no registros oficiales de Fórmula 1. La página actual contiene nombres de estudiantes; anonimiza los nombres de terceros antes de promocionarla como material público.

**Alcance:** ejercicio de aprendizaje frontend, no una aplicación de datos deportivos en vivo.
