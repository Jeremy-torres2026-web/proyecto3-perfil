# F1 Team Profiles — Responsive Frontend Exercise

**English / Español**

## English

### Overview

A collaborative frontend exercise that presents Formula 1 team and driver information in a compact, card-based interface. The page focuses on making profile information easy to scan and demonstrating a simple interaction that reveals predefined sample statistics.

### Interaction and implementation

HTML defines the profile structure, CSS Flexbox and responsive rules arrange the cards, and vanilla JavaScript handles the button event that reveals predefined sample values. The content is stored in the page rather than retrieved from a sports API.

### Skills demonstrated

- Semantic HTML and structured content.
- Responsive card layouts with CSS Flexbox.
- DOM selection and event handling in JavaScript.
- Updating visible content from predefined data.
- Collaborative development and version control.

### Technology

HTML5, CSS3 and vanilla JavaScript.

### Run locally

Open **index.html** in a modern browser. No backend or external dependencies are required.

### Data and scope

Team and driver information is presented as an interface exercise. Statistics are illustrative sample values, not official or live Formula 1 data. The page is not connected to a sports API.

## Español

### Descripción general

Ejercicio frontend colaborativo que presenta información de equipos y pilotos de Fórmula 1 mediante una interfaz compacta basada en tarjetas. La página busca que los perfiles sean fáciles de consultar y demuestra una interacción sencilla para revelar estadísticas predefinidas de ejemplo.

### Interacción e implementación

HTML define la estructura de los perfiles, CSS Flexbox y las reglas responsivas organizan las tarjetas, y JavaScript puro procesa el evento del botón que revela valores adicionales de muestra. El contenido está almacenado en la propia página y no se obtiene mediante una API deportiva.

### Competencias demostradas

- HTML semántico y contenido estructurado.
- Maquetación adaptable con CSS Flexbox.
- Selección del DOM y gestión de eventos con JavaScript.
- Actualización de contenido visible mediante datos predefinidos.
- Desarrollo colaborativo y control de versiones.

### Tecnologías

HTML5, CSS3 y JavaScript puro.

### Ejecución local

Abre **index.html** en un navegador moderno. No requiere backend ni dependencias externas.

### Datos y alcance

La información de equipos y pilotos se presenta como ejercicio de interfaz. Las estadísticas son valores ilustrativos, no datos oficiales ni información en vivo de Fórmula 1. La página no está conectada a una API deportiva.
